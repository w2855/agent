对话

自定义指令注入每一轮对话；网络类失败按指数退避自动重试。

个性化提示词

保存后立即对新对话生效；也在聊天空态里点「个性化提示词」直达这里。

自动重试
失败自动重试 限流、5xx、网关超时与网络中断会自动重试：2s → 4s → 8s 指数退避，服务端给了 Retry-After 就按它等；参数错误与鉴权失败不重试。
会话数据

把当前会话保存为文件：包含标题与全部消息正文，工具调用清单与审批记录一并保留，可选 Markdown 或 JSON 两种格式。

API 接入

桌面端本身不带运行时，不需要本地装 Ubuntu 或 Node；模型 API 走 OpenAI 兼容 /v1 端点。

离线预览使用内置的示例会话数据回放界面效果，不发起任何网络请求，也不会调用模型。用于断网时检查布局与交互；真实对话请切回「模型 API」。
